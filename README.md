# FASE I 
consiste en un juego de exploración y aventura dentro de una cueva, donde el jugador avanza por distintos niveles cada vez más difíciles hasta enfrentarse al jefe final. donde en este paso hicimos que tiene el juego como niveles, armas, enemigos, tesoros, jefe final. Sus mecánicas del juego y la adaptación para niños de 8-12 años
